# 📊 Next_Ventures Sales Data Analysis (Google Sheets Dashboard)

## 🚀 Project Overview
This project presents an **interactive sales dashboard** built using **Google Sheets**.  
It provides insights into sales performance, customer behavior, and business trends.

The goal of this project is to demonstrate data analysis and visualization skills using a real-world style dataset.
